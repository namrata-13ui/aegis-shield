# Third Parties and Cloud Security Policy

**Owner:** Vendor and Cloud Owner
**Review Date:** 22 April 2027
**Status:** Draft

## Purpose
Manage risks from external providers and cloud services.

## Scope
Cloud platforms, SaaS services, suppliers, contractors and integrations.

## Rules
1. Security review must occur before a vendor receives data or production access.
2. The review must record data types, access needs and incident-notification terms.
3. Vendor access must use named accounts and MFA where supported.
4. Cloud storage containing sensitive data must block public access by default.
5. Active vendor access must be reviewed every 90 days.
6. Contracts must define confidentiality and data return or deletion where applicable.
7. Access must be revoked when the contract ends.

## Roles
Business owners approve vendors; Security reviews risk; IT manages access.

## Exceptions
Exceptions require documented approval and an expiry date.

## Review
Review every six months.
