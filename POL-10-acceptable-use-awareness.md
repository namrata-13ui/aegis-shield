# Acceptable Use and Security Awareness Policy

**Owner:** HR and Security Lead
**Review Date:** 22 April 2027
**Status:** Draft

## Purpose
Set expectations for safe use of organisational systems.

## Scope
All employees, contractors and authorised users.

## Rules
1. Users must use accounts and devices only for authorised purposes.
2. Users must not install unapproved software or bypass security controls.
3. Suspicious emails and links must be reported through the approved channel.
4. Users must lock unattended devices.
5. Users must complete security awareness training at onboarding and annually.
6. Lost devices and suspected data disclosure must be reported immediately.
7. Training completion and reported violations must be recorded.

## Roles
Users follow the policy; HR tracks training; Security provides awareness material.

## Exceptions
Exceptions require documented approval and an expiry date.

## Review
Review every six months.
