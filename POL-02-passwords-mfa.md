# Passwords and MFA Policy

**Owner:** Security Lead
**Review Date:** 22 April 2027
**Status:** Draft

## Purpose
Protect accounts from unauthorised access.

## Scope
All user and administrator accounts.

## Rules
1. MFA must be enabled for all administrator accounts.
2. MFA must be enabled for remote access.
3. Passwords must be at least 14 characters when password-only authentication is used.
4. Work passwords must not be reused on personal services.
5. Passwords and recovery codes must not be shared or stored in plain-text files.
6. Suspected exposed credentials must be reset promptly.
7. Authentication systems must limit repeated failed login attempts.

## Roles
Security Lead defines requirements; IT configures controls; users protect credentials.

## Exceptions
Exceptions require written approval, compensating controls and an expiry date.

## Review
Review every six months.
